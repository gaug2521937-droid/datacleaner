Обычный пароль Google — без «паролей приложений». Письма уходят с вашего Gmail через Gmail API по HTTPS, поэтому это работает и на бесплатном хостинге, где SMTP закрыт.

Аккаунт не подключён вход в один клик

Почта для отправки (SMTP)

Пароль хранится в зашифрованном виде (Fernet) и никогда не отдаётся в браузер.

Для Gmail/Яндекса/Mail.ru нужен «пароль приложения», а не пароль от почты.

Что произойдёт

Каждый новый черновик уйдёт оператору автоматически — в течение выбранного интервала.
Если ответа нет дольше срока — уйдёт повторное требование (один раз на запрос, без спама).
Все действия пишутся в историю запроса: когда отправлено, когда напомнили, что ответил оператор.
Пока DRY_RUN=1, письма не уходят: автопилот только отмечает, что отправил бы. Выключите DRY_RUN на сервере для реальной отправки.
